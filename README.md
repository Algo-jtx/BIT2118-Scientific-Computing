# BIT 2118 – Scientific Computing

## Project Overview

This repository contains Python implementations of Scientific Computing practical tasks (Tasks 2–20).

The project explores numerical methods used in scientific and engineering applications, including matrix operations, linear systems, root finding, interpolation, curve fitting, numerical differentiation, integration, differential equations, optimization and Monte Carlo simulation.

## Technologies Used

- Python
- NumPy
- SciPy
- Matplotlib

## Project Structure

- code/: Python programs for Tasks 2–20
- results/: Generated graphs
- documentation/: Practical report .md file
- requirements.txt: Required Python libraries

## Setup Instructions

Create and activate a virtual environment:

    python3 -m venv .venv
    source .venv/bin/activate

Install dependencies:

    pip install -r requirements.txt

## Running a Program

Run an individual task from the project root:

    python code/Task_02_numpy_arrays.py

Replace the filename with the task you want to execute.

## Results

Generated graphs are saved in the results/ directory.

## Documentation

The documentation/ directory contains the practical report describing the input data, numerical methods, outputs, interpretations and parameter changes.
